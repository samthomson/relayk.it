The dashboard tracks the server itself: CPU, memory and disk usage, with thresholds that mark each as normal, warning or critical. When something crosses a line, the reason and the fix are shown with it — memory near capacity means add RAM, disk filling up means expand storage. A banner at the top surfaces warnings so they can't be missed.

## Logs

Every service has a logs view. When a relay won't start or Blossom rejects uploads, the logs are one click from the service card.
