---
title: Nostr auth
description: Sign in with the key you already have — one owner, no passwords.
order: 4
---

There is no username and password. You sign in with your Nostr key through a NIP-07 extension — Alby, nos2x and similar all work. An instance has one owner, set to your key during install.

Install also generates a recovery password for the underlying admin system — if you ever lose the Nostr key, it's the way back in. Store it somewhere safe.
